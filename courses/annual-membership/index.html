01

COURSE MODULE

模块一：饼干与常温点心

建立烘焙信心，理解「黄油状态」如何决定质地

第1课｜曲奇家族——三种经典质地一次掌握

  • 低糖奶油曲奇（酥脆型）——黄油打发法，理解充气与延展
  • 低糖雪球曲奇（酥松型）——粉油混合法，理解颗粒感与入口即化
  • 切片曲奇（整形型）——冷冻定型与切割技巧

核心原理　黄油的三态（固态/打发态/融化态）对曲奇质地的影响

学完你能做　任何黄油饼干的基础变形——香草曲奇、可可曲奇、坚果曲奇、夹心曲奇

第2课｜司康——英式下午茶的基石

  • 低糖蔓越莓司康——折叠法与层次生成原理

核心原理　干湿材料混合的「刚好成团」原则——过度搅拌起筋会变硬

学完你能做　咸司康、芝士司康、水果司康、全麦司康

02

COURSE MODULE

模块二：戚风蛋糕系统

掌握烘焙最核心的「泡沫支撑结构」——这个体系不仅覆盖戚风，还延伸到所有需要蛋白霜打发的蛋糕

第3课｜原味戚风——空气感蛋糕的原理

  • 蛋白霜的三阶段判断（湿性/中性/干性）
  • 翻拌手法与消泡控制
  • 烘烤温度曲线与塌陷预防
  • 脱模与冷却的完整流程

核心原理　戚风的本质是「蛋白泡沫+蛋黄糊」的双体系支撑——泡沫提供高度，蛋黄提供湿润

学完你能做　任何6寸/8寸戚风，包括加高戚风、中空戚风

第4课｜风味戚风延伸——粉类替换与口感变化

  • 抹茶戚风——粉类替换时的乳化平衡（抹茶粉吸油吸水特性）
  • 糯米戚风——淀粉种类对口感的影响（糯米粉带来的Q弹质地）

核心原理　粉类、油脂、液体三者的配比平衡——替换任何一种原料，如何补偿其他两种

学完你能做　可可戚风、红茶戚风、咖啡戚风、南瓜戚风、任何你想尝试的风味戚风

第5课｜舒芙蕾芝士蛋糕——蛋白霜与奶酪的融合

  • 分蛋法与蛋白霜的结合（与戚风同源，但奶酪糊更厚重）
  • 奶酪糊的温度控制（过热会消泡）
  • 水浴烘烤与组织细腻度的关系
  • 与巴斯克的对比：一个靠打发（轻），一个靠乳化（重）

核心原理　轻芝士蛋糕的「分蛋打发体系」——蛋白霜提供空气感，奶酪提供湿润度。本质上和戚风是同一套逻辑，只是多了奶酪的乳化体系

学完你能做　半熟芝士、轻乳酪蛋糕、任何需要「轻盈口感」的芝士甜品

03

COURSE MODULE

模块三：巴斯克蛋糕

第6课｜巴斯克芝士蛋糕

  • 奶油奶酪的软化与乳化技巧
  • 高温烘烤的梅纳反应与焦香生成
  • 流心/半熟/全熟的三状态判定

核心原理　巴斯克芝士蛋糕的「不打发体系」——依靠蛋液的凝固性+奶酪的乳化性支撑结构，和戚风/舒芙蕾完全不是一个逻辑

学完你能做　原味/抹茶/巧克力/开心果/任何口味巴斯克

04

COURSE MODULE

模块四：奶油系统

掌握奶油的状打发技巧与风味调配

第7课｜奶油的科学——打发与调味

  • 原味奶油——打发阶段判断：8分（裱花抹面）、9分（夹心）
  • 抹茶奶油——粉类预处理（避免颗粒）
  • 海盐奶油——咸味平衡与风味层次（咸如何衬托甜）

核心原理　乳脂含量、温度、打发速度的三元关系——控制这三者，就能控制奶油的一切

学完你能做　任何调味奶油、基础抹面与裱花

05

COURSE MODULE

模块五：面包系统

掌握面团的两种核心制法，理解「一个面团的千变万化」

第8课｜中种法吐司——一个面团，六款面包

  • 中种法原理：预发酵如何改善面团风味与老化速度
  • 中种面团的搅拌、发酵、整形完整流程
  • 一个面团的6款延伸：
  • 1. 白吐司（基础版，理解模具与烘烤）
  • 2. 奶酥包（馅料包入技巧）
  • 3. 肉松面包（表面装饰与层次）
  • 4. 红豆吐司（甜馅与面团的配比）
  • 5. 肠仔包（两种面团的拼接）
  • 6. 辫子吐司（整形手法与张力控制）

核心原理　中种法的「两阶段发酵」——第一阶段建立风味基底，第二阶段构建面筋网络

学完你能做　任何甜面包、餐包、排包——只要学会中种法，就掌握了面包的骨架

第9课｜贝果与软欧——低糖油面团的两种面貌

  • 全麦脆皮贝果：
  • 液种的制作
  • 水煮工艺的原理（糊化反应形成脆皮）
  • 贝果的整形与发酵控制
  • 液种面团的延伸应用：
  • 软欧包（液种面团，不同整形与烘烤）

核心原理　液种的「长时间低温预发酵」——在糖油有限的条件下，用时间和菌种深度挖掘面粉本身的风味层次，让低糖油面包不再寡淡

学完你能做　任何低糖油液种面包——贝果、软欧入门

06

COURSE MODULE

模块六：千层蛋糕系统

掌握薄饼皮的精准控制——烘焙中最考验「手感」的技法

第10课｜超薄千层——薄饼皮的可食用布料

  • 原味千层——面糊的乳化与静置（消泡与松弛）
  • 抹茶千层——粉类分散与色泽控制（抹茶不氧化）
  • 巧克力千层——可可脂与面糊的融合技巧
  • 煎锅温度控制与饼皮厚度的关系
  • 抹面组装与切面平整度的秘诀

核心原理　面糊的流变学——稠度决定厚度，温度决定凝固速度，锅温决定上色程度。三者构成「薄饼三角」

学完你能做　毛巾卷、班戟、可丽饼、任何薄饼类甜品
