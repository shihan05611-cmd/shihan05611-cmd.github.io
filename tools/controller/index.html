Controller_

Make multi-agent work
visible, bounded, reviewable.

将复杂任务拆成可追踪的图，为每个 Agent 路由独立会话、限定执行边界，并把 Review 变成结果的一部分。

01 / THE PROBLEM

并行并不等于协作。

当任务只靠聊天记录流动，依赖关系、权限边界、上下文归属和最终验收很快失控。Controller 用显式任务图保存这些关系。

核心能力

01

Task Graph

把任务、依赖与状态放入 DAG，使阻塞和可并行路径一眼可见。

02

Session Routing

让不同工作进入对应会话，减少长上下文反复处理与职责串线。

03

Guardrails

通过 allowlist、预算和状态约束，把 Agent 的动作限制在任务边界内。

04

Review Gate

执行结果必须经过独立 Review，接受、返工与证据形成可追溯闭环。
