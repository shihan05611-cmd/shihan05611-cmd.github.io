PROJECT 02GAME PROJECT · WEB2026

弈者

一款把角色能力带上棋盘、再用 Roguelike 路线不断改写阵容的策略游戏。

01 / DEFINITION

每个棋子都是角色，
每次行棋都是构筑。

项目把棋盘空间、角色技能、资源节奏与路线奖励放进同一局游戏。玩家不是背诵最优解，而是在变化的条件下持续重组策略。

02 / DESIGN PROBLEM

A

规则可读

角色能力丰富，但行动范围、目标与结果必须在落子前清楚表达。

B

随机但可控

起始角色、路线与奖励提供变化，同时保留足够信息让玩家做有依据的选择。

C

长期节奏

单场对局、章节成长和永久成长需要彼此区分，避免数值成长吞掉策略空间。

03 / KEY SYSTEMS

01

Character-shaped pieces

棋子职业提供基础规则，角色技能负责打破规则，两层共同决定队伍身份。

02

Run as a decision arc

起始选择、节点、遗物与奖励构成连续决策链，让阵容在一局中逐渐成形。

03

Observable balance

固定配置、种子和策略做可复现对比；模拟结果用于发现问题，不替代真实内容验收。

04 / PROCESS

Rules → Simulation → Play

先把规则写成可观察指标，用批量模拟检查极端情况，再回到实际对局判断节奏、理解成本与选择质量。
