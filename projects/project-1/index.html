元素回廊

一款由元素附着与连锁反应驱动的动作 Roguelike，让每次攻击既是伤害，也是下一次选择的铺垫。

01 / DEFINITION

让元素不是伤害颜色，
而是战斗的语法。

玩家通过附着、触发与消费元素制造连锁反应。系统的价值不只在组合数量，而在于每一步都能被看见、被预测、被利用。

02 / DESIGN PROBLEM

A

信息密度

状态很多，但玩家必须在移动中迅速理解当前元素与可触发反应。

B

反馈层级

普通伤害、附着、反应和击退需要不同视觉权重，避免特效淹没规则。

C

构筑延展

技能升级要改变决策方式，而不只是让数值持续变大。

03 / KEY SYSTEMS

01

Readable reaction chain

状态图标、命中文案、位移方向和短时特效共同解释一次反应，而不是依赖单个飘字。

02

Skill as transformation

升级围绕范围、消耗方式、持续时间与触发窗口，形成不同作战节奏。

03

Feedback ownership

视觉反馈跟随实际目标与世界坐标，保持多目标战斗中的空间可信度。

04 / PROCESS

Prototype → Observe → Clarify

先用可运行原型验证规则，再通过固定场景与同镜头截图检查信息是否真的传达。自动测试保证语义稳定，窗口实机画面负责视觉验收。
